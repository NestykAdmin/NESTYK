## E. วิธีรัน build สำหรับเทส

```bash
cd apps/consumer-app
# env ตาม docs/deploy/web/agent.nestyk.com.env.example
# อย่างน้อย: EXPO_PUBLIC_WEB_PORTAL=agent  EXPO_PUBLIC_WEB_SIGN_OUT_TO=login
npm run build:web
npm run serve:web      # serve dist/ พร้อม fallback ไป index.html (refresh deep path ได้)
```

- ข้อมูลทดสอบใน dev DB ใช้ชื่อขึ้นต้น `QA-` หรือ `E2E-` เพื่อให้ลบง่าย (มีของเดิมค้างอยู่: lead `MILD-QA-0911` และนัดที่ยกเลิก 1 รายการ)
- บนเซิร์ฟเวอร์จริงยังไม่มี `vercel.json` (SPA rewrite) จึงยังเทส refresh deep path บน Vercel ไม่ได้
