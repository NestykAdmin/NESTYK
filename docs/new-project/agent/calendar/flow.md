# Agent calendar — flow

1. เปิดเมนูปฏิทินในโหมด Agent ภายใต้ shell เดิม
2. เริ่มแสดงเดือนและวันที่ปัจจุบัน พร้อมป้ายบอกว่าส่วนไหนเป็นข้อมูลจริง/จำลอง
3. ดึงนัดดูห้องจริงของเดือนที่แสดง (`GET /agent/viewings`) แล้วรวมกับรายการจำลอง — เลื่อนเดือนจะดึงใหม่ ดึงไม่สำเร็จจะแสดงเฉพาะรายการจำลอง
4. เลือกวันเพื่อดูรายการนัด จุดใต้วันที่แสดงว่ามีนัด เลื่อนเดือนหรือกดวันนี้ได้
5. วันที่ไม่มีนัดแสดง empty state พร้อมปุ่มเพิ่มนัด
6. เพิ่มนัด (จำลอง): เลือกประเภท กรอกหัวข้อ สถานที่ (ไม่บังคับ) และเวลา `HH:mm` — บันทึกลง state เรียงตามเวลา พร้อมสถานะรอติดต่อ
7. ยกเลิกปิดฟอร์มโดยเก็บร่างไว้ สลับเมนูเก็บรายการ/วันที่/เดือน/ร่างไว้จนรีโหลด

นัดดูห้องจริงสร้าง เลื่อน และยกเลิกจากหน้าห้องที่จับคู่กับลีด ([leads/viewings.md](../leads/viewings.md)) — ปฏิทินแสดงอย่างเดียว
