# Agent calendar — flow

1. เปิดปฏิทินโหมด Agent แสดงเดือนและวันที่ปัจจุบัน
2. ดึง `GET /agent/viewings` และ `GET /agent/calendar/events` แยกกันตามเดือนที่แสดง; แสดงแหล่งที่สำเร็จได้ทันที หากบางแหล่งล้ม แจ้งชื่อแหล่งและให้ลองใหม่เฉพาะส่วนนั้น
3. เลือกวันเพื่อดูรายการเรียงตามเวลาไทย พร้อมจำนวนรายการบนวันที่มีนัด; เลื่อนเดือนแล้ววันที่เลือกย้ายตาม โดยไม่เกินวันสุดท้ายของเดือน
4. กดเพิ่มนัดหมายแล้วเปิดหน้าต่างให้กรอกหัวข้อนัดหมาย สถานที่ (ไม่บังคับ) และเวลา `HH:mm`
5. กดสร้างแล้วการ์ดใบเดิมเปลี่ยนเป็นหน้ายืนยัน กดสร้างอีกครั้งจึงส่ง `POST /agent/calendar/events`; กดยกเลิกหรือปิดแล้วกลับไปที่ฟอร์ม ระหว่างรอปิดการกดซ้ำ ถ้าส่งไม่สำเร็จค้างหน้ายืนยันไว้ให้ลองใหม่
6. สำเร็จแล้วล้างร่าง ปิดฟอร์ม แสดงข้อความยืนยันและโหลดรายการใหม่; หากล้มเหลวแสดงข้อผิดพลาดและเก็บข้อมูลในฟอร์ม
7. refresh เปิดหน้าใหม่ หรือเริ่มแอปใหม่จะอ่านนัดที่บันทึกจากฐานข้อมูล; Dashboard แสดงนัดทั้งหมดของวันนี้ รวมรายการที่เลยเวลาแล้วตาม Asia/Bangkok
8. นัดที่เพิ่มเองมีไอคอนแก้ไขและยกเลิก โดยไม่มีสถานะหรือปุ่มทำเสร็จแล้ว; กดแก้ไขแล้วยืนยัน หน้าต่างเดิมเปลี่ยนเป็นฟอร์มแก้หัวข้อ สถานที่ และเวลาแบบตอนสร้าง แล้วกดบันทึก ปิดหรือยกเลิกแล้วไม่บันทึก วันที่ยึดตามวันที่ของนัดนั้น และต้องยืนยันก่อนยกเลิก โดยเก็บประวัติในฐานข้อมูล
9. สร้างหรือเลื่อนนัดจะแสดงคำเตือนนัดใกล้กันจากทั้งสองแหล่ง โดยยังบันทึกต่อได้; หากโหลดข้อมูลไม่ครบจะแจ้งว่าตรวจนัดชนได้ไม่ครบ

นัดดูห้องจาก Lead สร้าง เลื่อน และยกเลิกผ่านหน้าห้องที่จับคู่กับ Lead เช่นเดิม ([leads/viewings.md](../leads/viewings.md))
