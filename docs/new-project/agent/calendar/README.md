# Agent — Calendar

เมนู **ปฏิทิน** ใน Consumer App โหมด Agent แสดงนัดดูห้องจาก Lead และนัดที่เพิ่มจากปฏิทินซึ่งบันทึกในฐานข้อมูลจริง

- ปฏิทินรายเดือน เลื่อนเดือน เลือกวัน กลับวันนี้ และดึงข้อมูลใหม่ด้วย pull-to-refresh; เมื่อเลื่อนเดือน วันที่เลือกจะย้ายตามและปรับไม่ให้เกินวันสุดท้ายของเดือน
- นัดดูห้อง: `GET /agent/viewings` — สร้าง/เลื่อน/ยกเลิกจากหน้าห้องที่จับคู่กับ Lead ดู [leads/viewings.md](../leads/viewings.md)
- นัดจากปฏิทิน: `GET` / `POST` / `PATCH /agent/calendar/events/:id` — เพิ่ม แก้หัวข้อ สถานที่ วันเวลา หรือยกเลิกโดยเก็บประวัติ ไม่ผูก Lead หรือห้อง
- รายการนัดใน Calendar และ Dashboard ไม่มีป้ายสถานะหรือปุ่มเปลี่ยนสถานะ เหลือหัวข้อ สถานที่ และเวลา พร้อมการแก้ไขและยกเลิกนัดที่เพิ่มเอง
- ต้องกรอกหัวข้อ (สูงสุด 160 ตัวอักษร) และเวลา `HH:mm`; สถานที่ไม่บังคับ (160)
- สร้างนัดใหม่กรอกในหน้าต่างใบเดียว แล้วกดสร้างเพื่อสลับเป็นการ์ดยืนยันก่อนเรียก API; แสดงว่าบันทึกสำเร็จหลัง API บันทึกแล้วเท่านั้น ถ้าล้มเหลวค้างหน้ายืนยัน เก็บร่างไว้ และแสดงข้อผิดพลาด
- เปิดหน้าใหม่ เปลี่ยนเดือน หรือ refresh จะโหลดข้อมูลจริง; ไม่มีรายการตัวอย่าง
- Dashboard รวมนัดทั้งสองแหล่งทั้งหมดของวันนี้ รวมรายการที่เลยเวลาแล้ว ตามเขตเวลา Asia/Bangkok พร้อมหัวข้อนัดหมาย
- รองรับ TH/EN/ZH/JA และธีมสว่าง/มืด
- วันและเวลานัดใน Lead, Calendar และ Dashboard ใช้ Asia/Bangkok เหมือนกัน แม้เครื่องตั้งเขตเวลาอื่น; API เก็บ UTC
- คำเตือนนัดใกล้กันภายในหนึ่งชั่วโมงรวมทั้ง Lead และนัดที่เพิ่มเอง ไม่นับตัวเอง นัดดูห้องที่ทำเสร็จแล้ว หรือนัดที่ยกเลิก รวมกรณีข้ามเที่ยงคืน และไม่บล็อกการบันทึก นัดที่เพิ่มเองไม่ใช้สถานะเสร็จสิ้นในการตรวจนัดใกล้กัน
- โหลดแต่ละแหล่งแยกกัน: แสดงผลที่สำเร็จก่อน เก็บข้อมูลเดิมเมื่อ refresh ล้ม แจ้งแหล่งที่ล้ม และลองใหม่เฉพาะแหล่งนั้น

## ไฟล์หลัก

- `apps/consumer-app/components/AgentCalendarBody.tsx` — โหลดข้อมูลและบันทึกผ่าน API
- `apps/consumer-app/components/AgentCalendarScreen.tsx` — ปฏิทินและฟอร์ม
- `apps/consumer-app/lib/agent-calendar.ts` — วันเวลาไทย การเปลี่ยนเดือน สถานะ และการตรวจนัดใกล้กัน
- `apps/consumer-app/lib/agent-calendar-api.ts` — API client
- `apps/consumer-app/lib/agent-calendar-viewings.ts` — ช่วงวันที่และแปลงนัดดูห้อง
- `apps/api/src/agent/calendar/` — API แยกข้อมูลตาม Agent ที่เข้าสู่ระบบ
- `supabase/migrations/20261016082206_agent_calendar_events.sql` — ตารางนัดหมาย พร้อม RLS
- `supabase/migrations/20261016085246_calendar_management.sql` — เพิ่มสถานะ scheduled / done / cancelled โดยคงข้อมูลเก่า
