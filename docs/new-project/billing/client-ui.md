# Billing — หน้าจอฝั่งแอป

ฝั่งแอปมีหน้าที่ **แสดงผล** สิทธิ์เท่านั้น — ทุกการตัดสินอยู่ที่ server ([api.md §3](./api.md#3-การตรวจสิทธิ์ฝั่ง-server))

---

## 1. แหล่งข้อมูลสิทธิ์

- `apps/consumer-app/lib/entitlements.ts` — เรียก `GET /me/entitlements` และ cache ในหน่วยความจำ
- hook `useEntitlements()` คืน `{ plan, feature(key), refresh() }`
- โหลดใหม่เมื่อ: login · กลับเข้าแอป (`AppState` → `active`) · ซื้อ/กู้คืนสำเร็จ · ได้ `PLAN_LIMIT` หรือ `FEATURE_LOCKED`
- หลังงานที่ตัดโควตาสำเร็จ ให้ใช้ `remaining` จากผลลัพธ์อัปเดตตัวเลขทันทีโดยไม่ต้องโหลดใหม่

---

## 2. รูปแบบหน้าจอ

| สถานการณ์ | แสดงอย่างไร | Component |
|-----------|-------------|-----------|
| ปุ่มงานที่มีโควตา | ป้าย "เหลือ 7/10" บนปุ่ม · หมดแล้วปุ่มยังกดได้ แต่เปิดแผ่นอัปเกรดแทน | `MobileAiQuotaAction` (`@nestyk/ui`) |
| ตัวเลือกที่ถูกล็อก | **แสดงตัวเลือกไว้** พร้อมไอคอนกุญแจ (`#64748B`) · กดแล้วเปิดแผ่นอัปเกรด ไม่ซ่อน | ไอคอน `lock` + แถวตัวเลือกเดิม |
| ค่าที่เกินสิทธิ์ (`max`) | ตัวเลือกที่เกินแสดงกุญแจ เช่น "50 ห้อง" ในแพ็กเกจ free | |
| ค่าที่ถูก clamp | ข้อความเล็กใต้ผลลัพธ์ "ใช้คะแนนขั้นต่ำ 50% ตามแพ็กเกจปัจจุบัน" | |
| `grace` | แถบเตือนสีส้ม (`warning`) ด้านบน "ชำระเงินไม่สำเร็จ — อัปเดตวิธีชำระเงิน" | |

ห้ามซ่อนฟีเจอร์ที่ล็อกทั้งหมด — ผู้ใช้ต้องเห็นว่ามีอะไรให้อัปเกรด

---

## 3. แผ่นอัปเกรด (`UpgradeSheet`)

เปิดจาก: ตัวเลือกที่ล็อก · `PLAN_LIMIT` · `FEATURE_LOCKED`

- ใช้ `MobileBottomSheet` (ห้าม `Modal animationType="slide"`) · ปิดด้วยปุ่ม Back ของ Android
- เนื้อหา:
  - หัวข้อจาก `billing.featureHints.<key>` (เช่น "ปรับคะแนนขั้นต่ำได้ในแพ็กเกจ Pro")
  - กรณีโควตาหมด: "ใช้ครบ 10 ครั้งแล้ว · รีเซ็ต 1 พ.ย."
  - เทียบ 2–3 จุดเด่นของแพ็กเกจที่ต้องใช้ (`requiredPlan`)
  - ปุ่มหลัก "ดูแพ็กเกจ" → หน้าแพ็กเกจ · ปุ่มรอง "ไว้ทีหลัง"
- ระยะ A–B ([flow.md §6](./flow.md#6-ระยะการเปิดใช้)) ยังไม่มีหน้าซื้อ — ปุ่มหลักแสดง "เร็วๆ นี้" แบบปิดไว้

---

## 4. หน้าแพ็กเกจของฉัน

เข้าจากเมนูด้านข้าง (drawer) ของ role ที่มีฟีเจอร์เสียเงิน

- แพ็กเกจปัจจุบัน · สถานะ · วันต่ออายุหรือวันหมดอายุ
- ยอดใช้แต่ละโควตาในรอบนี้ (แถบความคืบหน้า + "รีเซ็ตวันที่ …")
- การ์ดแพ็กเกจที่เปิดขาย ราคาจาก SDK ของสโตร์ ([payments.md §2](./payments.md#2-revenuecat-มือถือ))
- ปุ่ม "กู้คืนการซื้อ" · "จัดการการสมัคร" (เปิดหน้าการสมัครของสโตร์)

## 5. คีย์ i18n

เพิ่มครบ `th.ts` / `en.ts` / `zh.ts` / `ja.ts` + `types.ts` ใต้ `billing.*`

| คีย์ | ตัวอย่าง (th) |
|------|---------------|
| `billing.plans.free` / `pro` / `business` | ฟรี · Pro · Business |
| `billing.planDescriptions.<code>` | สำหรับเริ่มต้นใช้งาน |
| `billing.features.<key>` (แทน `.` ด้วย `_`) | `agent_match_run`: จับคู่ห้อง |
| `billing.featureHints.<key>` | `agent_match_min_score`: ปรับคะแนนขั้นต่ำได้ในแพ็กเกจ Pro |
| `billing.quotaLeft` | เหลือ {remaining}/{limit} |
| `billing.quotaUnlimited` | ไม่จำกัด |
| `billing.quotaResetsOn` | รีเซ็ต {date} |
| `billing.limitReached` | ใช้ครบ {limit} ครั้งแล้ว |
| `billing.locked` | ใช้ได้ในแพ็กเกจ {plan} |
| `billing.clampedNotice` | ใช้ {label} ตามแพ็กเกจปัจจุบัน |
| `billing.upgrade` / `billing.later` / `billing.comingSoon` | ดูแพ็กเกจ · ไว้ทีหลัง · เร็วๆ นี้ |
| `billing.myPlan` / `billing.restore` / `billing.manage` | แพ็กเกจของฉัน · กู้คืนการซื้อ · จัดการการสมัคร |
| `billing.graceBanner` | ชำระเงินไม่สำเร็จ — อัปเดตวิธีชำระเงิน |

ข้อความภาษาไทยทุกจุดต้องมี `lineHeight` ≥ 1.45 เท่าของ `fontSize`
